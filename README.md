# Lumina Dental Studio

A concept website for a premium, modern dental studio in Bonifacio Global City (BGC), Taguig.

## Overview

Lumina Dental Studio is a self-initiated portfolio project exploring how a dental practice can move beyond the conventional sterile, text-heavy clinic website and create a calmer, more premium patient experience.

The project combines clinical trust, wellness-inspired visual design, clear information architecture, and a low-friction appointment journey.

## Role

**Lead Product Designer & Frontend Developer**

## Project Type

Concept / self-initiated freelance portfolio project

## Timeline

2 weeks

## Goals

- Elevate the perceived quality of a dental brand.
- Reduce cognitive load when exploring dental services.
- Build trust through clinicians, technology, and clear information.
- Make appointment intent simple and accessible.
- Demonstrate responsive, accessible frontend implementation.

## Design Direction

**Crisp, Clean & Tech-Forward**

The visual system blends clinical precision with the calm atmosphere of a premium wellness studio.

### Core palette

- White `#FFFFFF`
- Soft Gray `#F8F9FA`
- Charcoal `#2B2D42`
- Soft Mint `#4CA794`

### Typography

- Plus Jakarta Sans — headings and prominent UI
- Inter — body and supporting content

## Built With

- HTML5
- CSS3
- JavaScript
- CSS Grid & Flexbox
- Responsive design
- Accessible interaction patterns

## UX Highlights

- Streamlined service information architecture.
- Human-focused doctor profiles.
- Trust and technology cues.
- Responsive mobile navigation.
- Appointment-focused conversion path.
- Accessible focus and reduced-motion considerations.
- Purposeful micro-interactions.
